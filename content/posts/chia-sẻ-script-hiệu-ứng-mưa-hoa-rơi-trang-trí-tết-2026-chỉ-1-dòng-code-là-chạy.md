Không khí Tết Bính Ngọ 2026 đang tràn ngập khắp nơi. Để giúp các bạn "thay áo mới" cho website đón Tết một cách nhanh chóng nhất, mình xin chia sẻ bộ Script hiệu ứng **"Mưa Hoa Rơi"** (kết hợp cả Hoa Đào và Hoa Mai).

Điểm đặc biệt là mình đã đóng gói toàn bộ mã nguồn vào một file duy nhất, các bạn không cần biết lập trình, chỉ cần **Copy & Paste** là chạy.

## Demo Hiệu ứng

Sau khi nhúng script, website của bạn sẽ có hiệu ứng:

* Những cánh **Hoa Đào (Hồng)** và **Hoa Mai (Vàng)** rơi nhẹ nhàng từ trên xuống.
* Hoa tự động xoay và lắc lư theo gió rất tự nhiên.
* Hiệu ứng nằm dưới các nút bấm, **không che khuất nội dung** hay làm phiền người dùng.

## Tại sao bạn nên dùng Script này?

Khác với các hiệu ứng cũ dùng ảnh động (GIF/PNG) gây nặng máy, Script này được viết bằng công nghệ **HTML5 Canvas**:

1. **Siêu nhẹ:** Không tải thêm bất kỳ hình ảnh nào, tốc độ tải trang gần như không đổi.
2. **Mượt mà:** Chuyển động đạt 60FPS, không gây giật lag web.
3. **Dễ dùng:** Chỉ cần 1 dòng code duy nhất.

## Hướng dẫn cài đặt

Bạn chỉ cần copy đoạn mã dưới đây và dán vào file giao diện của website (thường là file `footer`, đặt trước thẻ đóng `</body>`).

Hiệu ứng 1:
![](/images/hieu-ung-tet.jpg)
```html
<script src="https://loclaptrinh.com/js/hieu-ung-tet.js"></script>
```
Hiệu ứng 2:
![](/images/hieu-ung-tet-2.jpg)
```html
<script src="https://loclaptrinh.com/js/hieu-ung-tet-2.js"></script>
```

### Cách chèn vào các nền tảng phổ biến:

* **WordPress:** Vào *Appearance (Giao diện)* -> *Theme File Editor* -> Chọn file `footer.php` và dán code vào trước thẻ `</body>`. Hoặc dùng plugin *Insert Headers and Footers*.
* **Landing Page (LadiPage, Haravan...):** Vào phần *Cài đặt mã JavaScript/CSS* và dán vào mục *Trước thẻ Body*.
* **Code tay (HTML/PHP/Laravel):** Dán trực tiếp vào file Layout chính của bạn.

Hy vọng món quà nhỏ này sẽ giúp website của bạn thêm phần lung linh, rực rỡ để đón chào năm mới.
